Synergy: the tokens

One source file, tokens/synergy.json, writes the Blocks pair (synergy-light.json, synergy-dark.json), synergy-style.json and the website's tokens.css. This page wears the Blocks pair through Blocks' own css(). Both schemes pass Blocks' gate under tint, outline and solid fills.
